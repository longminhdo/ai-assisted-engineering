Hypotheses Before Fixes

Hypothesis-Driven Loop
Problem → Hypothesis → Evidence → Experiment → Fix → Verify. Converges.
Random-Change Loop
Guess → change → rerun → guess again. Flat, no evidence, dead ends.

Implement approach 1. Constraints: preserve behavior, no public API changes, no new dependencies, keep the diff minimal.

Ask It to Prove You Wrong

Weak
"Is this code good?"

→ generic agreement. Useless.
Strong
"Try to prove this implementation is wrong. Find inputs, states, or interactions that could cause incorrect behavior."
